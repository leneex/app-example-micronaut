# Micronaut

Пример приложения [Micronaut](https://micronaut.io/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/` |

Railpack видит Maven: ставит JDK 21, собирает проект через `./mvnw` и запускает собранный jar из
`target/`. Приложение слушает порт из переменной окружения `PORT` — её передаёт платформа, — а без
неё `8000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
./mvnw dependency:resolve

# запуск в режиме разработки
./mvnw mn:run

# сборка для продакшн и запуск
./mvnw package && java -jar target/app-example-micronaut-0.1.jar
```

Нужен JDK 17 или новее. Maven нужной версии `./mvnw` скачает сам.
